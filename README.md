i don't know what im doing, but here's what I've built anyway.

I mod VR games — mostly multiplayer. But I code in C#, C, C++ & Lua and have a strong understanding in Steamworks Networking & Creating Syncronised Multiplayer modificatons for games that where never supposed to have them. :)

## 🔧 Projects

### [Entanglement Redux](https://github.com/willpsdk/Entanglement-Redux)
An alternative multiplayer mod for BONEWORKS, rebuilt on Steamworks with a rewritten networking and object sync layer. Steam-based lobbies, synced physics, full player sync.

### [totf-multiplayer](https://github.com/willpsdk/totf-multiplayer)
A experimental multiplayer mod for *The Thrill of the Fight* — VR boxing - This was just a Demo I made with some friends.

### [Rockstar Editor Enhanced](https://github.com/willpsdk/Rockstar-Editor-Enhanced)
A little Scripthook ASI Plugin I made to change and fix some issues with the Rockstar Editor, mainly higher bitrate exports & fps and tabbing out or losing focus of the game keeps the recording going.
